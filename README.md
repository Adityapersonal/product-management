# 🛒 Product Management API

A Spring Boot REST API for managing products.  
Built to showcase clean architecture, CRUD operations, and professional testing practices.

---

## 🚀 Features
- Create, read, update, and delete products
- RESTful endpoints with JSON responses
- Layered architecture (Controller → Service → Repository → Entity)
- JPA/Hibernate integration
- Unit and controller tests with MockMvc
- Ready for PostgreSQL or H2 (in-memory) database

---

## 🛠️ Tech Stack
- **Java 17**
- **Spring Boot 3**
- **Spring Data JPA**
- **PostgreSQL / H2 (for tests)**
- **JUnit 5 & Mockito**
- **Maven**
